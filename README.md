# campuslands-gestion-operativa
Sistema MVP de gestión operativa para Campuslands desarrollado en 5 horas por Paz David Samid y Juan Diego. Integra control sin solapamientos de aulas, préstamo seguro de recursos tecnológicos y triaje automatizado de incidencias mediante IA. Una solución integral que optimiza procesos universitarios con alta eficiencia y robustas reglas de negocio
